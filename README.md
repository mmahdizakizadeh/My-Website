# MMahdi Zakizadeh | Personal Portfolio

A personal portfolio website showcasing my work, experience, interests, and ideas at the intersection of **design, code, and engineering**.

This website represents my professional identity as a Front-End Developer, UI/UX Designer, and Mechanical Engineer. It provides a personal space to explore my background, selected projects, articles, and creative interests.

**Live Website:** [mmahdizakizadeh.github.io/My-Website](https://mmahdizakizadeh.github.io/My-Website/)

---

## Overview

This project is a responsive, single-page personal portfolio designed to introduce me and present my professional interests, experience, and selected work.

The design combines editorial typography, a clean layout, subtle animations, and a carefully balanced color palette to create a modern and comfortable browsing experience.

The website reflects my interest in combining engineering principles, creative thinking, and modern web technologies.

## Website Sections

- **Home** — Personal introduction and overview.
- **About Me** — Background, professional interests, and personal philosophy.
- **Experience** — A timeline highlighting my learning journey and experience.
- **Projects** — A showcase of selected development and creative projects.
- **Articles** — An editorial space for sharing ideas, observations, and technical interests.
- **Contact** — Links to my contact information and social profiles.

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Mobile-friendly navigation menu.
- Light and dark mode.
- Theme preference persistence using Local Storage.
- Dynamic header behavior based on scroll direction.
- Smooth scrolling and reveal animations.
- Intersection Observer API for scroll-based animations.
- Keyboard navigation support.
- Visible focus states for interactive elements.
- Reduced motion support for accessibility.
- Semantic HTML structure.
- SEO-friendly metadata.
- Open Graph and Twitter Card metadata.
- Schema.org structured data.
- Custom SVG favicon.
- Organized CSS architecture.
- Reusable CSS custom properties for colors and transitions.

## Getting Started

You can run this project locally without installing additional dependencies.

### 1. Clone the Repository

```bash
git clone https://github.com/mmahdizakizadeh/My-Website.git
```

### 2. Navigate to the Project Directory

```bash
cd My-Website
```

### 3. Run the Website

Open `index.html` directly in your browser.

Alternatively, you can use the **Live Server** extension in Visual Studio Code for a local development environment.

No additional installation or build process is required.

## Responsive Design

The website is designed to provide a consistent experience across different screen sizes.

Responsive styles are maintained separately in `css/responsive.css`, making the layout easier to manage and extend.

The implementation includes dedicated breakpoints for:

- Desktop screens.
- Tablet devices.
- Mobile devices.
- Small mobile screens.

## Customization

The visual design is organized around CSS custom properties, allowing the main design values to be modified easily.

### Colors and Themes

The main color variables are defined in `:root`, while dark mode uses dedicated overrides.

This approach makes it possible to customize the website's color palette without manually changing values throughout the stylesheets.

### Transitions and Animations

Reusable CSS variables are used to manage transition timing and visual interactions.

You can customize animation speed and other visual properties directly in the main stylesheet.

### Website Content

To update personal information, project descriptions, experience, articles, or contact links, edit the corresponding sections in `index.html`.
